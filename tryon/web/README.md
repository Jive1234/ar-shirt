# AR Try-On เวอร์ชันเว็บ (MediaPipe + three.js)

ลองเสื้อ 3D ผ่านเว็บแคมแบบ real-time ในเบราว์เซอร์ ไม่ต้องลงโปรแกรม ไม่ต้อง build

**เปิดใช้งาน:** หลัง merge เข้า branch หลัก จะอยู่ที่ `https://jive1234.github.io/ar-shirt/tryon/web/`
(ต้องเปิดผ่าน https หรือ localhost เพราะเบราว์เซอร์ให้ใช้กล้องเฉพาะบนหน้าที่ปลอดภัย)

## วิธีใช้
1. กด **เปิดกล้อง** แล้วอนุญาตกล้อง
2. ยืนให้เห็นตั้งแต่หัวถึงสะโพก หันหน้าตรง ปล่อยแขนลงกางออกเล็กน้อย ยืนนิ่ง ~2 วินาที (มีข้อความบอกว่าต้องแก้ท่าอะไร)
3. เสื้อจะปรากฏและขยับตามตัว เปลี่ยนสี / แขนสั้น-ยาว / วัดตัวใหม่ ได้จากปุ่มด้านล่าง
4. หลายคน (สูงสุด 3) แต่ละคนวัดตัวและได้เสื้อของตัวเอง

ตัวเลือกใน URL: `?src=clip.webm` ใช้ไฟล์วิดีโอแทนกล้อง · `?skipCalib=1` ข้ามการวัดตัว · `?debug=1` แสดง mask และเวลา · `?clothes=0` ปิด clothes mask (เร็วขึ้น) · `?people=1` จำกัดจำนวนคน · `?mirror=0|1`

ปรับค่าได้ที่ `src/config.js` (มุมกล้อง, สีเสื้อ, ความหลวม `ease`, ข้อความบนเสื้อ)
ถ้าเสื้อดูใหญ่หรือเล็กเกินตัวกับทุกคน ให้ปรับ `horizontalFovDeg` ก่อน

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `src/poseSource.js` | MediaPipe PoseLandmarker (หลายคน + mask รายคน) และ ImageSegmenter (mask เสื้อผ้า) |
| `src/oneEuro.js`, `src/smoother.js` | OneEuro filter ลดการสั่น |
| `src/tracker.js` | ให้ ID คงที่ต่อคน, filter และ calibration แยกคน |
| `src/calibration.js` | state machine วัดตัวจากท่ายืน 1.5 วินาที (ค่า median) |
| `src/body.js` | คำนวณความลึกและตำแหน่งข้อต่อ 3D ในพิกัดกล้อง |
| `src/garment.js` | เสื้อ 3D แบบ parametric สร้างรอบตัวจากข้อต่อทุกเฟรม ขนาดตามค่าที่วัด ชายเสื้อและปลายแขนเป็น cloth (Verlet) |
| `src/occluder.js` | ตัวบังที่มองไม่เห็นสำหรับแขน มือ หัว |
| `src/compositor.js` | รวมภาพกล้อง + เสื้อ และกลบเสื้อจริงที่โผล่ออกมา |

## ทดสอบ
`npm test` (Node 20+) ทดสอบ filter, calibration, tracker
ทดสอบทั้งระบบใน Chromium (ซอฟต์แวร์เรนเดอร์) ด้วยวิดีโอคนจริง 1 คนและ 2 คน: เสื้อวางตรงตัว, เปลี่ยนสีและแขนยาวได้, ท่า T-pose ถูกปฏิเสธพร้อมคำแนะนำ
**ยังไม่ได้วัด FPS บนเครื่องจริงที่มี GPU และยังไม่ได้ลองกับเว็บแคมจริง**

## ข้อจำกัด
- เสื้อเป็นแบบ parametric (สร้างจากโค้ด) ยังไม่รองรับไฟล์ .glb ของเสื้อจริง
- การกลบเสื้อจริงใช้สีของเสื้อ AR เติมขอบ ถ้าใช้เป็น kiosk กล้องตั้งนิ่ง เปิด `useBackgroundPlate` ใน config เพื่อใช้ภาพฉากหลังว่างแทน (เนียนกว่า แต่ถ้าใส่เสื้อจริงแขนยาวกับเสื้อ AR แขนสั้น แขนอาจถูกลบไปด้วย)
- คนยืนบังกันเองยังไม่ได้จัดการ
